# 운반비 월간보고 자동화 설계

## 1. 목적

화성공장 운반비 월간보고 업무에서 반복되는 실적 집계, 계획 대비 계산, 장기 평균 계산, PowerPoint 표 입력 및 그래프 교체를 자동화한다.

최종 PowerPoint의 6장 구성과 시각적 형식은 유지한다. Excel 내부 구조는 자동화에 적합하도록 재구성할 수 있다.

## 2. 현재 업무의 핵심 문제

- 월별 종합 시트를 복제하여 사용하므로 수식과 월 제목이 어긋날 수 있다.
- 실적 수량, 운반비, 매출 및 평균값이 여러 영역에 수기로 입력된다.
- 장기 이력 및 그래프 데이터가 월간 종합표와 완전히 연결되어 있지 않다.
- PowerPoint의 표와 그래프는 Excel 연결 개체가 아니라 정적인 표와 이미지다.
- 동일 수치를 Excel 표, 차트, PowerPoint 표, PowerPoint 텍스트 상자에 반복 입력한다.
- 현재 8월 보고서의 6장에는 9월 계획값이 들어 있지만 제목은 8월 계획으로 남아 있다.

## 3. 선택한 접근 방식

별도 로컬 웹 관리화면, 통합 데이터 저장소 및 기존 PowerPoint 템플릿을 결합한다.

- 로컬 웹 관리화면은 기준정보, 납품처 별칭, 사용자 정의 그룹, 월계획, 매출실적 및 오류 검토를 관리한다.
- 통합 데이터 저장소는 원천 운행실적과 설정값을 보관한다.
- Excel은 원천자료 가져오기 및 필요 시 검토용 계산 결과 내보내기에 사용하며, 자동화 시스템의 마스터 저장소로 사용하지 않는다.
- PowerPoint는 기존 형식을 유지하되, 표 값과 그래프 이미지를 자동으로 교체한다.
- 증감 대상 선정과 수치 원인 계산은 자동화한다.
- 파업, 긴급납품, 고객 요청 등 정성적 원인은 담당자가 최종 입력한다.

기존 월별 시트를 계속 보수하는 방식은 구조적 오류가 남으므로 채택하지 않는다. 중앙 서버나 사내 공용 웹 시스템은 현재 업무 규모보다 구축·운영 부담이 크므로 최초 범위에서 제외한다.

## 4. 로컬 웹 관리 및 데이터 구조

### 관리화면

- 보고 월 선택 및 보고서 생성
- 표준 납품처와 원천파일 별칭 관리
- 차량 톤수별 기준운반비 및 대표 품목 관리
- 사용자 정의 그룹과 그룹 구성 납품처 관리
- 수량·운반비·매출 포함 여부 등 그룹별 집계 예외 관리
- 월계획과 보고 월 매출실적 입력
- 보고 월의 납품처별 실제 납품수량(EA) 입력
- 미등록 납품처, 누락 단가 및 검증 오류 처리
- 마스터 변경사항의 즉시 계산 반영

`영남권`은 고정 수식으로 만들지 않고 사용자 정의 그룹으로 관리한다. 초기 구성은 현대 울산, 포레시아 영천, 세종공업이며, 사용자가 구성원을 추가하거나 삭제하면 해당 그룹의 수량, 운반비, 대당 운반비 및 PowerPoint 출력값을 다시 계산한다.

당진처럼 지표마다 포함 조건이 다른 항목은 수량, 운반비, 매출의 포함 여부를 각각 설정한다.

원천파일에서 처음 발견한 납품처명은 `미등록 명칭` 목록에 표시한다. 사용자가 기존 표준 납품처에 별칭으로 연결하거나 새 표준 납품처로 등록하면 이후 업로드부터 자동 적용한다. 미등록 명칭이 남아 있으면 PowerPoint 생성을 중단한다.

### 통합 데이터 저장소

로컬 웹 관리화면이 사용하는 데이터 저장소에는 다음을 보관한다.

- 표준 납품처와 별칭
- 차량 톤수별 기준운반비
- 대표 품목
- 사용자 정의 그룹과 구성원
- 지표별 집계 포함 여부
- 운행실적과 원천 행 식별값
- 월계획과 매출실적
- 보고서 생성 이력 및 검증 결과

### 실행 및 이동 방식

시스템은 단일 사용자용 Windows 무설치형 로컬 애플리케이션으로 구성한다. 개발에 사용한 노트북에서 완성된 배포 폴더를 사용자의 전용 작업 PC로 복사하면 같은 기능을 실행할 수 있어야 한다.

- 프로그램 코드에 특정 PC의 절대 경로를 저장하지 않는다.
- 실행파일, 웹 화면, 데이터 저장소, PowerPoint 템플릿 및 설정을 하나의 배포 폴더에 포함한다.
- 관리자 권한, 별도 Python·Node.js 설치 및 별도 데이터베이스 설치를 요구하지 않는다.
- 배포 폴더의 실행파일을 누르면 로컬 서버가 시작되고 기본 브라우저에 관리화면이 열린다.
- 프로그램 종료 기능을 제공하고, 중복 실행 시 기존 관리화면으로 연결한다.
- 원천 Excel 입력 폴더와 결과 Excel·PowerPoint 출력 폴더는 관리화면에서 선택할 수 있게 한다.
- 최초 실행 시 필요한 폴더와 기본 설정을 자동 생성한다.
- 마스터 데이터와 이력은 배포 폴더의 데이터 파일로 함께 이동하거나, 관리화면에서 백업·복원할 수 있게 한다.
- 인터넷 연결 없이 로컬 PC에서 실행할 수 있게 한다.
- Windows 사용자명과 드라이브 문자가 달라도 동작해야 한다.
- 배포 폴더 전체를 복사하면 프로그램, 마스터 데이터, 설정 및 보고서 이력을 함께 이동할 수 있어야 한다.

- 보고 연월

- 증감 검토 기준값(기본 ±15%)
- PowerPoint 출력 파일명 및 저장 위치
- 보고 월 매출실적 수기입력값
- 평균 기준연도: 보고연도 직전 연도로 자동 설정

### 기준정보

- 표준 납품처명
- 납품처 별칭
- 권역
- 대표 품목
- 차량 톤수
- 기본 운반비
- 합짐 추가비 및 배분 기준

### 운행실적

운행 한 건을 한 행으로 저장한다.

- 운행일자
- 배차 또는 차량 식별값
- 차량 톤수
- 납품처
- 적재수량
- 기본 운반비
- 합짐 추가비
- 납품처별 배분 운반비
- 정규·비정규 구분
- 용차 업체
- 원천 파일 및 원천 행 식별값

합짐 운행은 납품처별 적재수량 비율로 총 운반비를 배분한다. 동일 원천 행이 중복 반영되지 않도록 원천 식별값을 유지한다.

최초 구현에서는 ERP 실제 납품수량을 자동으로 가져오지 않는다. 담당자가 ERP에서 확인한 납품처별 실제 납품수량(EA)을 관리화면에 직접 입력한다. 해당 월의 필수 납품처 수량이 입력되지 않으면 PowerPoint 생성을 중단한다. 실제 수량이 0인 경우에는 빈칸과 구분되는 명시적 `0` 입력을 허용한다.

향후 ERP에서 내려받은 Excel을 업로드하면 품번별 수량을 읽고, `품번 → 표준 납품처` 마스터에 따라 납품처별 수량으로 합산할 수 있도록 수량 입력 모듈의 경계를 분리한다. ERP 가져오기와 품번 매핑 화면은 최초 구현 범위에서 제외하고 후속 업그레이드로 추가한다.

### 월계획

- 계획 연월
- 납품처
- 계획 수량
- 계획 운반비
- 계획 매출
- 대표 품목

실제 매출액은 다른 팀에서 전달받는 값이므로 외부 파일과 자동 연동하지 않는다. 담당자가 관리화면의 보고 월 매출실적 입력란에 직접 입력하며, 입력 출처와 확인일을 함께 기록할 수 있게 한다.

### 월간계산

보고 연월을 기준으로 다음을 계산한다.

- 납품처별 계획 및 실제 수량
- 납품처별 계획 및 실제 운반비
- 계획 및 실제 대당 운반비
- 계획 대비 증감액과 증감률
- 매출액 대비 운반비
- 3개월·6개월·12개월 평균
- 평균 구간은 보고 월을 포함하지 않고 직전 달을 끝으로 계산한다. 예를 들어 2026년 8월 보고서는 3개월 평균을 2026년 5~7월, 6개월 평균을 2026년 2~7월, 12개월 평균을 2025년 8월~2026년 7월로 계산한다.
- 영남권 등 권역 집계
- 비정규 운반비
- 증감 검토 대상

`대당 운반비`는 현재 보고서의 명칭을 유지하되, 계산식은 납품처별 및 전체 합계 모두 `운반비 ÷ 납품수량(EA)`로 정의한다. 계산 결과의 의미와 단위는 제품 1EA당 운반비(원/EA)다.

월별 종합 시트를 복제하지 않는다. 하나의 계산 구조가 선택한 보고 월을 표시한다.

### Excel 검토 출력

필요한 경우 월간계산 결과와 검증 내역을 `.xlsx` 파일로 내려받을 수 있게 한다. 이 파일은 검토 및 보관용이며, 사용자가 이 파일을 수정해 마스터 데이터를 변경하지는 않는다.

### PPT출력

PowerPoint의 각 표와 그래프가 사용하는 최종 데이터를 제공한다.

- 2장 월간 종합표
- 2장 증감 원인표
- 3장 최근 12개월 계획·실적 수량
- 4장 최근 12개월 계획·실적 운반비
- 5장 최근 12개월 수량·운반비 복합 실적
- 6장 다음 달 계획표

## 5. 데이터 흐름

```text
화성공장 운행실적 및 용차 Excel 업로드
                    ↓
             통합 데이터 저장소
                    ↓
로컬 웹 관리화면의 기준정보 + 월계획 + 매출실적
                    ↓
                 월간계산
                    ↓
        Excel 검토 출력 + PPT출력
                    ↓
           기존 6장 PowerPoint 갱신
```

## 6. PowerPoint 갱신 규칙

기존 PowerPoint의 슬라이드 수, 배치, 글꼴, 색상, 표 크기 및 결재란을 유지한다.

### 1장 표지

- 보고 월과 작성일을 자동 변경한다.
- 제목 형식은 `YY년 M월 화성공장 운반비 보고`를 사용한다.

### 2장 운반비 종합

- 월간 종합표의 모든 수치를 자동 입력한다.
- 계획, 실적, 증감, 평균, 합계, 매출 및 매출 대비 운반비를 포함한다.
- ±15% 초과 납품처를 하단 검토표에 자동 배치한다.
- 계획 운행 횟수, 실제 운행 횟수, 회당 적재수량, 기준 적재수량 및 적재율을 계산한다.
- 정성적 원인은 담당자 입력값을 사용한다.

### 3장 수량 그래프

- 보고 월을 끝으로 하는 최근 12개월 계획·실적 수량을 표시한다.
- 보고연도 직전 연도의 평균 수량 기준선을 표시한다. 예를 들어 2026년 보고서는 25년 평균, 2027년 보고서는 26년 평균을 사용한다.
- 현재 `1월 종합`에 보관된 그래프의 디자인을 유지한다.

### 4장 운반비 그래프

- 보고 월을 끝으로 하는 최근 12개월 계획·실적 운반비를 표시한다.
- 보고연도 직전 연도의 평균 운반비 기준선을 표시한다.
- 단위는 천원으로 표시한다.

### 5장 복합 그래프

- 실제 수량과 실제 운반비를 함께 표시한다.
- 보고연도 직전 연도의 평균 수량 및 평균 운반비 기준선을 표시한다.

### 6장 다음 달 계획

- 보고 월 다음 달의 계획을 표시한다.
- 제목의 연월은 계획 데이터의 실제 연월에서 생성한다.
- 다음 달 계획이 없으면 PowerPoint 생성을 중단하고 누락 항목을 표시한다.

## 7. 오류 처리와 검증

PowerPoint 생성 전에 다음 검증을 모두 통과해야 한다.

- 납품처명이 기준정보에 등록되어 있다.
- 차량·납품처 조합에 필요한 운반비 기준이 있다.
- 운반비가 있는 행에는 운행 횟수 또는 수량이 있다.
- 원천 운행 행이 중복되지 않았다.
- 납품처 합계와 전체 합계가 일치한다.
- 대당 운반비 계산에서 0으로 나누는 오류가 없다.
- 계획 월, 실적 월, 보고서 제목의 월이 일치한다.
- 다음 달 계획 데이터가 존재한다.
- 보고 월 매출실적과 확인일이 입력되어 있다.
- 보고 월의 필수 납품처별 실제 납품수량이 입력되어 있다. 빈칸은 누락으로 처리하고 명시적 0은 정상 입력으로 처리한다.
- 그래프 마지막 월이 보고 월과 일치한다.
- Excel 출력값과 PowerPoint 표의 값이 일치한다.

검증 실패 시 PowerPoint를 생성하지 않고 오류 목록과 수정 위치를 보여준다.

## 8. 구축 우선순위

### 1단계: 통합 데이터 구조

운행실적, 용차 내역, 합짐 배분, 기준정보 및 월계획을 표준화한다.

### 2단계: 로컬 웹 관리화면

납품처·별칭·단가·대표품목·사용자 정의 그룹·월계획·매출실적을 관리하고, 미등록 항목을 검토할 수 있게 한다.

### 3단계: 월간 계산

현재 8월 종합 결과와 동일한 값을 새 계산 구조에서 재현한다.

### 4단계: 검증

누락, 중복, 단가 오류, 합계 불일치, 보고 월 불일치를 탐지한다.

### 5단계: PowerPoint 생성

기존 템플릿의 표, 제목, 날짜, 그래프 및 파일명을 자동 갱신한다.

### 6단계: 증감 원인 보조

수치 원인을 자동 제시하고 정성적 원인을 담당자가 보완한다.

최초 구현 범위는 1~5단계다. 6단계는 핵심 자동화가 검증된 후 추가한다.

## 9. 완료 기준

- 기존 8월 보고서의 계획·실적·합계가 새 계산 결과와 일치한다.
- 보고 월을 바꾸어도 월별 시트 복제가 필요 없다.
- 기존 PowerPoint 형식이 유지된다.
- 2장과 6장 표가 Excel 출력값과 일치한다.
- 3~5장 그래프가 보고 월 기준 최근 12개월을 표시한다.
- 6장 제목이 실제 다음 달 계획과 일치한다.
- 입력 누락 또는 오류가 있으면 보고서 생성을 차단한다.
- 담당자가 수행하는 작업은 원천자료 입력, 오류 확인, 정성적 원인 보완 및 최종 검토로 제한된다.
- 마스터 데이터와 사용자 정의 그룹을 관리화면에서 수정하면 월간계산, Excel 검토 출력 및 PowerPoint 결과에 자동 반영된다.

## 10. 제외 범위

- ERP나 외부 시스템과의 직접 연동
- ERP Excel 자동 가져오기 및 품번→납품처 매핑 마스터
- 승인·전자결재 자동화
- 정성적 증감 원인의 완전 자동 작성
- 기존 PowerPoint 디자인 변경

## 11. 미결 위험

- 정성적 증감 원인은 담당자의 검토 없이 확정하지 않는다.
- 작업 PC의 보안 정책이 출처가 확인되지 않은 실행파일 또는 로컬 서버 실행을 차단할 수 있으므로 실제 PC에서 배포본 실행 검증이 필요하다.
