# 운반비 보고 프로그램

1. 배포받은 `TransportReport` 폴더 전체를 원하는 위치에 복사합니다.
2. 폴더 안의 `TransportReport.exe`를 실행합니다. 이미 실행 중이면 기존 화면이 브라우저에서 열립니다.
3. 회사 보안 정책에 따라 Windows 보안 검토가 표시되면 사내 절차에 맞게 실행을 허용합니다.
4. 자동으로 열린 브라우저에서 납품처·그룹 마스터와 월별 입력값을 관리합니다.
5. 검증 결과를 확인한 뒤 Excel 검토파일 또는 PPT를 생성해 `runtime\outputs`에서 엽니다.
6. 다른 PC로 옮기기 전 화면의 백업 기능으로 백업한 뒤 `TransportReport` 폴더 전체를 복사합니다.
